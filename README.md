## 📌 소개

`my-link`는 나만의 프로필 및 중요한 링크들을 한눈에 보여줄 수 있는 반응형 웹 페이지입니다. 다크 모드와 반응형 디자인을 지원하며, 손쉽게 커스터마이징할 수 있습니다.

## 🚀 시작하기

### 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속하여 결과를 확인할 수 있습니다.

### 빌드 및 배포

```bash
npm run build
npm run start
```

## 🛠 기술 스택

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19
- **Styling**: Tailwind CSS v4
- **Language**: TypeScript
